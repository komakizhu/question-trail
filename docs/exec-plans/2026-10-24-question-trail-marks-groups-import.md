## 数据与兼容

- 使用新存储字段 `questionTrailV2`，旧 `questionTrail` 保留原样；读取时惰性转换并经一次成功保存后写入 V2。新格式损坏时禁止写回。
- 单条记录包含答案、`important`、`wholeUncertain`、`unknown`、`uncertainOptions` 与旧标记审计字段；重做追加历史，不覆写原条目。
- 导入来源身份由试卷、版本、作答身份及稳定题目身份组成；人工确认后绑定到 Markdown 文件路径和块 ID。
- 导入预览确认前不写数据；确认时在一次串行持久化事务中保存记录和身份绑定。相同修订跳过，变化修订追加，冲突整批拒绝；明确排除的未支持行不阻止其余行。
- Skill 生成的 `question-trail-sync` 复用同一导入与去重流程，接收目录为 `<vault>/.obsidian/plugins/obsidian-exam-notes/import-inbox/`；只有 Skill 收到用户确认后才写入。插件未运行时保留文件，下次启用时接收。
- Skill 联动只同步最终答案和标记；后续修改答案或标记时追加修订，不同步或修改题干、选项文字、笔记及待复查状态；来源批改结果不得推断或替代个人标记。
- 不把答题卡答案用于评分。参考答案仍仅由当前 Markdown 的解析区读取。

## 题组规则与验收

- 只将题前存在、ID 唯一且被连续子题明确引用的同文件 `exam-material` 作为题组。缺失、重复、歧义或成员不连续则维持原显示。
- 外层题组、共用材料、子题背景透明并跟随主题；各层独立折叠，折叠状态按文件和材料块 ID 保存。
- 组级重做同步打开每个未提交的子题会话，不清除既有草稿；逐题保存，答案、标签、关联、笔记和个人脚注按既定重做范围遮盖。
- 验证 v2/v3 JSON/CSV、引号和换行字段、选项 ID 映射、重复导入和来源修订；验证旧历史迁移、保存失败不确认、重载和重命名。
- 验证标记共存和颜色组合、单题/整组重做、折叠恢复、材料复制与脚注；覆盖材料缺失、重复块 ID、普通 Callout、阅读视图、Live Preview、浅深主题及窄屏。
- 安装后逐项比较 `main.js`、`manifest.json`、`styles.css`，确认 `data.json` 未被替换；回滚恢复 0.3.2 运行文件并保留 V2 数据供后续升级。
